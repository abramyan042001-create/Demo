# База данных простого Django-примера

Три предметные таблицы: portal_user, portal_course, portal_application. Дополнительные поля пользователя и служебные таблицы создаёт стандартная система авторизации Django.

- У одного пользователя может быть много заявок.
- У одного курса может быть много заявок.
- В заявке user_id и course_id ссылаются на соответствующие id.
- Отзыв хранится в самой заявке: отдельная таблица для одного текста здесь не нужна.

models.py — то, что нужно понимать и учиться писать. migrate создаёт таблицы по истории миграций. schema.sql здесь только справочный экспорт фактических трёх таблиц, а не второй способ установки проекта. Не импортируй его поверх базы Django.

ER построена по настоящим полям SQLite; при требовании эксперта сделай дополнительный экспорт из выданной программы работы с СУБД.
