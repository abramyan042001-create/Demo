# Пакеты для установки без интернета

В полном файле Demo_offline.zip рядом с этим README лежат четыре wheel-пакета и SHA256SUMS.txt. Это сторонние библиотеки; их внутренний исходный код не является написанным для задания кодом.

В GitHub хранятся исходники проекта и список фиксированных версий, а бинарные wheel-пакеты поставляются отдельно в офлайн-архиве. Если скачали только GitHub ZIP, подготовьте пакеты заранее при наличии интернета:

```bash
# Скачать Django и все зависимости в эту папку, не устанавливая их в системный Python.
python bootstrap.py --prepare
```

Потом запускайте `python bootstrap.py`. Обычный запуск использует `--no-index` и не загружает пакеты из сети.

Python и его стандартные модули venv/ensurepip должны быть установлены заранее. В Windows выбирайте установку pip и добавление Python в PATH. В Linux пакет python3-venv может потребовать предварительной установки средствами вашей ОС. Сам установщик Python в архив не входит.
