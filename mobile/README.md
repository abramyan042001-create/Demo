# Пять статических мобильных макетов

Отдельные файлы: login.html, register.html, applications.html, new-application.html, admin.html. Каждый имеет холст шириной 390 px и минимальной высотой 844 px. Длинные формы прокручиваются вертикально.

Это снимки новых Django-шаблонов с вымышленными учебными данными. Можно открыть двойным щелчком и переходить между макетами. Формы в этих файлах не отправляют данные. Рабочая логика находится в Django views, а пояснения строк разметки — в templates/.
