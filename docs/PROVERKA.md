# Проверка простой учебной версии

## Что проверено

- `python manage.py check` — ошибок конфигурации нет.
- `python manage.py test` — 12 тестов пройдено.
- `python manage.py makemigrations --check --dry-run` — модель и история миграций согласованы.
- Каждая непустая строка Python проверена на наличие поясняющего комментария.
- Логика JavaScript отдельно проверена: ровно 4 кадра, движение по кругу, интервал 3000 мс, aria-hidden, надпись отправки и восстановление кнопки.
- SQL и ER обновлены по фактической упрощённой SQLite, старые поля в них не оставлены.
- Мобильные макеты пересозданы из новых шаблонов с вымышленными учебными данными.

12 серверных тестов проверяют регистрацию и хеш пароля, недопустимые поля, дубликат логина, вход Admin, выход через POST, закрытый кабинет, назначение владельца заявки, формат и существование даты, выбор курса и оплаты, запрет чужого отзыва, отзыв только после завершения, экранирование HTML, права администратора, фильтр, страницы списка, сохранение статуса и CSRF.

Визуальная проверка настоящим Chromium в этой среде недоступна из-за системного запрета Unix-сокетов. Серверные тесты и проверка JS не заменяют просмотр в браузере. Для подготовки проверь пять страниц при 390×844 и на широком экране: поля, переносы, стрелки слайдера, картинки и отсутствие горизонтальной прокрутки.

## Соответствие присланному официальному заданию

| Требование | Реализация |
| --- | --- |
| Полный стек и ООП | Django, наследование моделей/форм, SQLite, HTML/CSS/JS |
| Регистрация: уникальный логин, пароль, ФИО, телефон, email | RegisterForm и UserCreationForm |
| Проверки и сообщения на форме | Django forms, HTML-атрибуты и вывод field.errors |
| Вход и точный текст ссылки | AuthenticationForm и form.html |
| Просмотр своих заявок | filter(user=request.user) |
| Курс, дата ДД.ММ.ГГГГ и два способа оплаты | ApplicationForm |
| Три заданных курса | Команда seed и таблица Course |
| Администратор видит заявки всех | dashboard_view с проверкой is_staff |
| Смена на любой допустимый статус | StatusForm и status_view |
| Отзыв только после завершения | Проверка владельца и статуса в review_view |
| Фильтр, сообщения и пагинация | GET status, messages, Paginator по 5 записей |
| Ровно 4 одинаковых изображения, 3 секунды, стрелки | 4 фото 800×450, slider.html и app.js |
| Медиа из приложения | Логотип image01 и фото image06–09 из второго архива |
| Мобильные HTML 390×844 | Пять файлов в mobile/ |
| Адаптив, анимации и качество кода | Короткий CSS с media query, появление карточек, fade слайдов, индикатор |
| Схема и связи БД | db/schema.sql и db/er_diagram.svg |

ER автоматически нарисована по фактической SQLite. Если эксперт требует экспорт именно через DBeaver/Workbench/pgAdmin, открой выданную БД в разрешённой программе и сохрани её ER отдельным изображением. Это действие выполняется на площадке, готовый SVG нельзя называть скриншотом DBeaver.

SQLite — один из вариантов из пособия. На подготовительном этапе нужно сверить разрешённую СУБД и подключение к серверу площадки. Миграции исходников не заменяют самостоятельное проектирование БД в день экзамена.

## Что специально осталось простым

Нет дополнительных механизмов блокировки конкурентных запросов, своих декораторов и отдельных слоёв сервисов. Формы и права проверяются сервером, пароли хешируются стандартным Django. Это понятный учебный вариант для воспроизведения, не шаблон публичной системы с высокой нагрузкой.

Каждая непустая строка написанного кода пояснена по просьбе пользователя. Сгенерированные миграции тоже снабжены комментариями, но начинать обучение с них не нужно.
