| `python manage.py test` | 19 тестов пройдено; внутри есть дополнительные варианты subTest |

## Что не подтверждено браузером

Chromium в текущей среде не стартовал: системный запрет создания AF_UNIX-сокета привёл к остановке до открытия страницы. Поэтому здесь нет утверждения о пройденной визуальной проверке реального браузера, отсутствии переполнения на каждой ширине или полном браузерном e2e-сценарии. Node-проверка использует минимальную модель DOM и не проверяет CSS.

Перед экзаменом выполните раздел «Настоящий браузер» из CHECKLIST.md на своём компьютере: 5 страниц при 390×844 и на широком экране, стрелки и автосмена слайдера, формы, ошибки, отсутствие горизонтальной прокрутки, индикатор и работа без внешней сети.

## Что зависит от комплекта площадки

- Официальные фото/логотипы не были приложены: используются собственные SVG.
- SVG-диаграмма сгенерирована по реальной SQLite скриптом, а не экспортирована через UI DBeaver. Если нужен именно такой экспорт, сделайте его в выданной программе.
- SQLite выбран из предложенных в пособии вариантов. Разрешённый движок и офлайн-драйвер сверяются на подготовительном этапе площадки.
- Установщик Python не включён: Python и системные компоненты venv/pip готовятся заранее.
