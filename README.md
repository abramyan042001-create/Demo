# Корочки.есть

Модуль 1: Django + SQLite. Регистрация, вход, заявки, роли, отзывы.

Запуск: установите requirements.txt; выполните python manage.py migrate и python manage.py seed. При seed введите пароль администратора из задания. Затем python manage.py runserver.

На следующем этапе добавляются дизайн и офлайн-пособие.
