# Demo — простой Django для самостоятельной подготовки

**Это учебный пример, который нужно понять и научиться писать самому.** Оставлен Django, как ты попросил. Каждая непустая строка написанного кода объяснена по-русски: что делает, с какими данными работает и зачем нужна.

## С чего начать

1. Прочитай **[UCHEBNIK.md](UCHEBNIK.md)** — там порядок написания с нуля и разбор главных конструкций.
2. Открой **[portal/models.py](portal/models.py)** — сначала разберись, какие данные хранятся.
3. Потом **[portal/forms.py](portal/forms.py)** — как проверить ввод.
4. Затем **[portal/views.py](portal/views.py)** и **[portal/urls.py](portal/urls.py)** — как запрос попадает в функцию.
5. Разбери **[templates/](templates/)** — что видит пользователь и что отправляет кнопка.
6. Сделай задания из **[PRAKTIKA.md](PRAKTIKA.md)**, пробуя написать решение без подглядывания.

**Если скачал папку: открой `UCHEBNIK.html` в браузере.** Это тот же учебник и разбор исходников в формате «строка кода → объяснение». Для чтения не нужно запускать сайт, устанавливать Django или подключаться к интернету. На GitHub HTML показывается как исходник, а Markdown можно читать прямо по ссылке выше.

## Что упрощено

- Убраны установщик, офлайн-пакеты, дополнительные инструменты экспорта и сложная обработка параллельных запросов.
- Нет своих декораторов, общего универсального контроллера и дополнительных слоёв.
- Три модели: пользователь, курс, заявка.
- Обычные функции view с последовательными `if`, `is_valid`, `save`, `redirect`.
- Стандартная авторизация Django: не нужно самому писать хеширование и сессии.
- Простой CSS и небольшой JavaScript для четырёх кадров слайдера.
- Добавлены настоящие фотографии и логотип из твоего второго архива.

Логика задания сохранена: регистрация, вход, свои заявки, отзыв после завершения, администратор, смена статуса, фильтр, страницы списка и мобильные макеты. Разрешён любой из трёх статусов администратора, как написано в официальном задании; лишний запрет перехода сразу к завершённому обучению убран.

## Что НЕ нужно учить наизусть

`portal/migrations/` генерирует Django. Первая миграция — история предыдущей версии, вторая переводит её в простую. Их нужно сохранять для воспроизводимости, но писать их вручную и начинать обучение с них не нужно. Собственные миграции на экзамене создаются командой `makemigrations`.

`portal/tests.py` — дополнительная проверка примера. Она не часть пяти обязательных страниц и не обязательный первый материал для изучения.

## Если захочешь попробовать запуск

Этот раздел нужен только для практики, а не для чтения пособия. Команды вводятся из папки с manage.py. Нужен установленный Python 3.10+, для подготовки удобно использовать 3.12.

```bash
# Установить Django; на экзамене использовать библиотеки, выданные площадкой.
python -m pip install -r requirements.txt
# Создать таблицы по сохранённым миграциям.
python manage.py migrate
# Добавить три курса и администратора; при первом запуске ввести пароль из задания.
python manage.py seed
# Включить локальный сервер и открыть http://127.0.0.1:8000/ .
python manage.py runserver
```

В Windows вместо `python` можно использовать `py -3`. Логин администратора — `Admin`. Пароль вводится при создании по условию задания и не публикуется в коде; символы скрыты при вводе. Запись в БД идёт через стандартный хеш Django.
